# Risks, unresolved questions, and organizer clarification draft

## Risk register

Priority reflects impact on eligibility or the scientific claim, not a fabricated probability.

| ID | Priority | Risk | Detection / mitigation |
|---|---|---|---|
| G1 | Critical | Wrong registration/eligibility assumptions | Verify every member, form receipt and applicable platform rules |
| G2 | Critical | Incompatible ownership or resource license | Inventory submitted/background assets and obtain specific clarification |
| S1 | Critical | Too few independent groups for central claim | Count biological units before model choice; collect more or narrow claim |
| S2 | Critical | Data leakage through compounds, donors, controls or duplicates | Locked group manifest and content-hash audit |
| S3 | Critical | Replay uses invented outcomes for unmeasured actions | Restrict to measured pool or conduct prospective validation |
| S4 | High | Proxy assay presented as real target-chip evidence | Separate evidence layers in every result table |
| S5 | High | Ordinary conformal guarantee applied under shift/adaptation | Independent audit stream and explicit validity assumptions |
| S6 | High | Mechanistic or transfer parameters unidentifiable | Parameter recovery, sensitivity, simpler comparison, target-only fallback |
| S7 | High | “Novel” method duplicates published optimization work | Closest-method reproduction and precise contribution statement |
| S8 | High | Endpoint label circularly derived from input features | Independent biological endpoint or transparent measurement task |
| S9 | High | Model abstains excessively to look accurate | Matched-coverage comparisons and abstention cost |
| E1 | High | Report cannot be reproduced by reviewers | Public core and independent clean-environment run |
| E2 | Medium | Hosted demo fails during review | Local execution route and clearly labeled recorded backup |
| C1 | Medium | Wrong rubric or bonus assumption | Optimize both published rubrics; exclude unconfirmed bonus |
| C2 | Medium | Unverified competitor claims influence strategy | Use public claims only as positioning evidence |
